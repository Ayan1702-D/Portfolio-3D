## 🚀 Features
- **3D Neural Network Hero:** Interactive particle system using `@react-three/fiber`.
- **Custom Physics Cursor:** Magnetic spring animations using Framer Motion.
- **Skill Sphere & Timeline:** 3D HTML overlays and GSAP DrawSVG scroll animations.
- **Resend Email Integration:** Secure contact form validation using Zod and React Hook Form.
